# Краснопарс — браузерное мини-приложение

Расширение Chrome и Firefox (Manifest V3). Запускается нажатием на значок «К» в панели браузера. Интерфейс работает внутри popup расширения: навигация расположена сверху, кнопка поиска находится внутри формы. Всё окно прокручивается целиком стандартной прокруткой браузера, без закреплённых панелей и вложенных областей прокрутки. Для работы не нужна вкладка с сайтом.

## Сборка

- `npm run build:extension` — готовая папка `extension/build/`.
- `npm run package:extension` — Chrome ZIP и Firefox XPI в `extension/`.

## Установка и обновление

- Chrome: `chrome://extensions` → режим разработчика → «Загрузить распакованное расширение» → выбрать `extension/build/`.
- Если расширение уже установлено из этой папки, достаточно нажать «Обновить» на его карточке.
- Закрепить значок расширения на панели Chrome и нажать на него. `index.html` отдельно в браузерной вкладке открывать не нужно.
- Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выбрать `extension/build-firefox/manifest.json` или XPI. Постоянная установка требует подписи Mozilla.

## Поведение popup

- При каждом открытии показывается форма поиска с сохранённым черновиком и фильтрами.
- Вкладка «Поиск» и кнопка «Новый поиск» всегда возвращают к форме.
- Последняя подборка доступна отдельной кнопкой. Её открытие повторно загружает существующий поиск без создания нового.
- Открытие истории не меняет черновик. Чтобы перенести условия старого поиска в форму, нажмите «Использовать этот запрос».
- Переход к новому поиску отменяет ожидание в popup; уже запущенное задание на сервере может продолжить работу и доступно через историю.
- Начало запроса до получения его ID требует открытого popup. После получения ID поиск выполняется сервером.
- Ошибки источников и истории имеют отдельные кнопки повторной загрузки. Их загрузка не блокирует друг друга.
- Зелёная волна проигрывается один раз после успешного действия. Простое открытие существующей подборки её не запускает.
- Разрешения доступа ограничены API `http://109.196.167.225:8080`. При смене `VITE_API_BASE_URL` нужно обновить `host_permissions` в исходном manifest перед сборкой.

## Проверки

`npm run test:extension` проверяет навигацию, восстановление состояния, отмену и таймауты, доставку выделенного текста, последовательную запись подборок, защиту от дублей, сохранение заметок при переносе/восстановлении, ошибки хранилища и состав CSV.

## Поиск выделенной новости

Выделите текст на странице, нажмите правую кнопку мыши и выберите «Найти эту новость в Краснопарсе». Расширение откроет popup и запустит поиск типа «Текст новости» с текущими периодом, регионом и источниками. При ошибке условий форма остаётся доступной для исправления. Текст длиннее 2000 символов не обрезается: его нужно сократить перед отправкой.

Если браузер не разрешил автоматически открыть popup, выделение сохраняется, а на значке появляется «1». Откройте расширение обычным нажатием — оно продолжит действие. Повторное открытие после обработки выделения не создаёт ещё один поиск. Расширение получает только текст, выбранный через меню, и адрес его страницы; разрешения на чтение всех вкладок не запрашиваются.

## Рабочие подборки

- В результатах выберите папку и нажмите «Сохранить» у публикации или «Сохранить все материалы».
- В разделе «Подборки» создавайте и переименовывайте папки, перемещайте материалы, пишите заметки и ставьте независимые отметки «Проверено», «Важное», «В отчёт».
- Поиск учитывает заголовок, выдержку, источник и заметку. Фильтры ограничивают текущую папку и отметку.
- Повторное сохранение той же ссылки в том же источнике не создаёт дубль и не перезаписывает заметки. Размещения в разных источниках остаются разными записями.
- Удалённые материалы попадают в корзину и восстанавливаются вместе с заметками. При удалении папки её материалы переходят в «Без папки».
- «Скачать CSV» выгружает текущую отфильтрованную подборку с заметками и отметками. Для отчёта из отмеченных материалов выберите «В отчёт». Используется общий интервал экспорта 20 минут в профиле браузера.
- Подборки хранятся в `storage.local`, независимо от истории поиска, и работают офлайн. Синхронизации с сайтом, другим компьютером или другим браузером нет. Удаление расширения очищает его локальное хранилище.
- Запись изменений выполняет фоновый процесс последовательно. Успешное сообщение появляется после записи; ошибки квоты отображаются без замены существующих данных. Заметки отправляются на сохранение при каждом изменении, без таймера, который мог бы потерять текст при закрытии popup.

Для фонового процесса используются разные манифесты: Chrome — `extension/build/manifest.json`, Firefox — `extension/build-firefox/manifest.json`. В Chrome применяется service worker, в Firefox — background script. Оба варианта входят в соответствующий архив.
