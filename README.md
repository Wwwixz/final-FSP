# Медиаслед — медиамониторинг соцсетей

Фронтенд прототипа на React, TypeScript, Tailwind CSS и Vite. Спецификация API подготовлена по техническому заданию из [`tz_final.pdf`](tz_final.pdf).

- [`openapi.yaml`](openapi.yaml) — OpenAPI 3.1.0: источники, асинхронный поиск VK/ОК/MAX, покрытие и ошибки, результаты, экспорт XLSX.
- [`docs/api-design.md`](docs/api-design.md) — сценарий клиента, соответствие ТЗ, состояния, дедупликация, даты и проектные решения.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте URL Vite из терминала. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Прототип

Реализованы экран мониторинга с одним полем запроса, датами, площадками, регионом, режимами охвата, выбором источников, состоянием поиска, результатами и XLSX; экран управления списком публичных источников; состояния поиска, пустой выдачи и ожидания. Экспорт создаёт таблицу публикаций и лист параметров поиска.

Бэкенд не подключён. Результаты и охват площадок демонстрационные; запросы локально проигрывают короткий сценарий, а XLSX помечает данные как демонстрационные. Нельзя считать примеры публикаций реальными или использовать их для мониторинга. API и UI следует связать после реализации сервера по `openapi.yaml`.

Примеры поисковых запросов и контракт API находятся в `POST /searches` спецификации. Спецификацию можно открыть в Swagger Editor или совместимом просмотрщике OpenAPI 3.1.
