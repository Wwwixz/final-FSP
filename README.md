# КрасноПарс — медиамониторинг соцсетей

Фронтенд прототипа на React, TypeScript, Tailwind CSS и Vite. API-клиент находится в [`src/api.ts`](src/api.ts).

- [`openapi.yaml`](openapi.yaml) и [`docs/api-design.md`](docs/api-design.md) описывают проектный контракт API. Фактические маршруты подключённого сервера и типы ответов перечислены в `src/api.ts`.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте URL Vite из терминала. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Подключение API

По умолчанию приложение работает с API `http://109.196.167.225:8080`. Другой адрес можно указать через переменную окружения:

```sh
copy .env.example .env
```

Переменная `VITE_API_BASE_URL` должна содержать адрес сервера без завершающего `/`.

Фронтенд загружает источники, регионы и историю поиска с сервера; выполняет асинхронный поиск с опросом статуса; показывает найденные публикации; управляет источниками через CRUD; удаляет записи истории и скачивает серверный XLSX-отчёт.

В справочнике источников можно добавить каналы Telegram и Дзена. Они хранятся в `localStorage` текущего браузера и помечены как ожидающие подключения. На странице поиска Telegram и Дзен показаны со статусом «Скоро»; выбор и поиск по ним пока заблокированы до подключения API. VK, OK и MAX продолжают работать через API.

В фильтре региона вариант «Все» запускает поиск без поля `region` в запросе к API. Поиск охватывает активные источники выбранных площадок, которые есть в справочнике сервера.

Кнопка «+» рядом с выбором площадок добавляет поля для ссылок на произвольные сайты. Ссылки сохраняются в `localStorage` и пока не передаются в поисковый API.
