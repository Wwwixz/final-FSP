# КрасноПарс — медиамониторинг соцсетей

Фронтенд прототипа на React, TypeScript, Tailwind CSS и Vite. Спецификация API подготовлена по техническому заданию из [`tz_final.pdf`](tz_final.pdf).

- [`openapi.yaml`](openapi.yaml) — OpenAPI 3.1.0: источники, асинхронный поиск VK/ОК/MAX, покрытие и ошибки, результаты, экспорт XLSX.
- [`docs/api-design.md`](docs/api-design.md) — сценарий клиента, соответствие ТЗ, состояния, дедупликация, даты и проектные решения.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Откройте URL Vite из терминала. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Подключение API

По умолчанию приложение работает с API `http://109.196.167.225:8080`. Другой адрес можно указать через переменную окружения:

```sh
copy .env.example .env
```

Переменная `VITE_API_BASE_URL` должна содержать адрес сервера без завершающего `/`.

Фронтенд загружает источники, регионы и историю поиска с сервера; выполняет асинхронный поиск с опросом статуса; показывает найденные публикации; управляет источниками через CRUD; удаляет записи истории и скачивает серверный XLSX-отчёт. API-клиент находится в [`src/api.ts`](src/api.ts).
