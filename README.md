# Медиамониторинг соцсетей

Фронтенд на React, TypeScript, Tailwind CSS и Vite. Интерфейс подключён к серверу по контракту [`api.md`](api.md). Старый [`openapi.yaml`](openapi.yaml) хранится в репозитории как проектная спецификация; фактические маршруты сервера описаны в `api.md`.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

По умолчанию запросы идут на `http://109.196.167.225:8080`. Для другого сервера создайте `.env.local` в корне:

```env
VITE_API_BASE_URL=http://localhost:8080
```

После изменения переменной перезапустите Vite. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Возможности

- Поиск по теме, событию, имени или тексту новости; период, регион, уточнение, режим выбранных или всех активных источников.
- Режим `real` по умолчанию. `demo` выбирается явно. В реальном режиме VK доступен через API, OK собирается скрепером, MAX может возвращать `UNAVAILABLE`.
- Необязательная проверка релевантности через ИИ с показом статуса подключения.
- Асинхронный поиск с опросом статуса каждые 1,5 секунды, прогрессом и отдельными ошибками источников. Уже найденные публикации остаются видимыми при частичном сбое.
- Постраничные результаты с серверной сортировкой, просмотр публикации и прямой ссылкой. Если дата отсутствует, отображается «Дата недоступна».
- Источники: добавление, редактирование, включение, отключение и удаление через API.
- История поисков и повторный запуск. Аналитика показывает только поля, доступные в текущем API: количество по источникам и показатели отбора.
- XLSX скачивается с сервера через `/api/search/{id}/export?format=xlsx`.

Сервер не отдаёт изображения публикаций, полный текст, комментарии, типы контента и временной ряд. Поэтому интерфейс не показывает вымышленные данные для этих полей. Если фронтенд открыт по HTTPS, сервер API тоже должен быть доступен по HTTPS, иначе браузер заблокирует HTTP-запросы как смешанный контент.
